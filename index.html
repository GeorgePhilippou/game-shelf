GitHub sync

Saves your shelf to the game-shelf repo, so it appears on every device you connect. Your games, ratings, notes and covers become public, and anyone with the link can see them but not change them.

  1. Create a token on GitHub.
  2. Under Repository access, choose Only select repositories, then game-shelf.
  3. Check that Contents is set to Read and write, then generate it.
  4. Paste it below. Do this once on each device.

This device saves to the game-shelf repo automatically a few seconds after each change.
